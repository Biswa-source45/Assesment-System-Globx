Section D: Coding (16 marks)
Q26. Balanced Brackets [8 marks]
A string made only of the characters ( ) [ ] { } is balanced if every opening bracket is closed by the same type of bracket, and brackets are closed in the correct order (the most recently opened bracket must be closed first). Write a program that tells whether the given string is balanced.
Input format
One line containing the string s.
Output format
Print YES if the string is balanced, otherwise print NO (upper case, one line).
Constraints
1 <= |s| <= 100000. s contains only the characters ( ) [ ] { }.
Sample
Input Output
{[()]} YES
([)] NO

Q26. Balanced Brackets - Approach: use a stack. Push every opening bracket. For a closing bracket, the stack must be non-empty and its top must be the matching opening bracket; pop it. At the end the stack must be empty. Time O(n), space O(n).
Reference solution (Python)
def is_balanced(s):
 pairs = {')': '(', ']': '[', '}': '{'}
 stack = []
 for ch in s:
 if ch in '([{':
 stack.append(ch)
 else:
 if not stack or stack.pop() != pairs[ch]:
 return False
 return not stack
s = input().strip()
print("YES" if is_balanced(s) else "NO")

Q27. Minimum Cost Path - Approach: dynamic programming. The best cost to reach cell (i, j) is its own cost plus the smaller of the best cost to reach the cell above and the cell on its left. Time O(N x M).
Reference solution (Python)
n, m = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]
for i in range(n):
 for j in range(m):
 if i == 0 and j == 0:
 continue
 best = float('inf')
 if i > 0:
 best = min(best, grid[i-1][j])
 if j > 0:
 best = min(best, grid[i][j-1])
 grid[i][j] += best
print(grid[n-1][m-1])

Detailed solution: Section E (SQL)
Reference query
SELECT d.dept_name,
 COUNT(*) AS above_avg_count
FROM employees e
JOIN departments d ON d.dept_id = e.dept_id
WHERE e.salary > (SELECT AVG(salary)
 FROM employees
 WHERE dept_id = e.dept_id)
GROUP BY d.dept_id, d.dept_name
ORDER BY above_avg_count DESC, d.dept_name ASC;
Expected output on the sample data: Engineering 2, Sales 1.
Marking: 3 marks for the correct result on the sample data and 6 marks for the hidden data. The hidden data should include a tie at the average, a department with no employees, a department where all salaries are equal and departments with the same count (to test the alphabetical tie-break).
