Q4. Balanced Brackets [8 marks]
A string made only of ( ) [ ] { } is balanced if every opening bracket is closed by the same type of bracket,
in the correct order. Write a program that tells whether the given string is balanced.
Input format
One line containing the string s.
Output format
Print YES if the string is balanced, otherwise print NO.
Constraints
1 <= |s| <= 100000.
Sample
Input: {[()]}   Output: YES
Input: ([)]     Output: NO

Answer Key and Solutions
For the examiner only. Do not share with candidates.

Answers: Q1 (b)   Q2 (c)   Q3 (b)

Q4 reference solution (Python). Keep the indentation:
s = input().strip()
pairs = {')': '(', ']': '[', '}': '{'}
stack = []
for ch in s:
    if ch in '([{':
        stack.append(ch)
    elif not stack or stack.pop() != pairs[ch]:
        print('NO')
        break
else:
    print('YES' if not stack else 'NO')
