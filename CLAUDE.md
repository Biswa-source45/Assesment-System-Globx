## Project memory (read this first)

- At the start of every task, read `PROGRESS.md` (what is done, what is next) and `DEPLOYMENT.md` (the agreed plan).
- After every implementation, edit, or decision, update `PROGRESS.md` in the same turn: add a dated entry under "Log",
  and keep "Current state" and "Next" accurate. Update the checklist in `DEPLOYMENT.md` section 11 when a milestone changes.
- Keep both files short and factual. No unrequested abstractions or over-engineering (ponytail mode).
- Never put secrets (API keys, passwords) in these files or in git. Demo passwords are generated by the seed, never hard-coded.
- Frontend rule: **JavaScript + JSX only, no TypeScript** (no `.ts`/`.tsx`, no type annotations). Stack: Vite, React, Tailwind, shadcn/ui in JS mode.
- Git rules: commit only when asked, never push (the user pushes). No `Co-Authored-By` or any Claude/AI attribution in commit messages.
  Never commit `graphify-out/`, `.claude/`, `CLAUDE.local.md`, `.env`, or `*.docx`.
